# Notice — version PC (V4.0)

## Installation

1. Télécharge [`DKJr-Panorama-Remaster-V4.0-PC.zip`](../telechargements/DKJr-Panorama-Remaster-V4.0-PC.zip) et décompresse-le.
2. Ouvre le fichier `Donkey Kong Jr. Panorama - Remaster V4.0.html` avec Chrome, Edge ou Firefox.
3. Au premier lancement, le jeu demande la **ROM d'origine** (voir le [README](../README.md#-rom-dorigine-non-fournie)) :
   clique sur **Choisir les fichiers** et sélectionne `gnw_dkjrp.zip`, ou les deux fichiers `cj-93.program` et `cj-93.melody`.
   Elle est mémorisée : c'est à faire une seule fois.

Tu peux aussi jouer directement en ligne, sans rien installer, depuis la page du projet (lien en haut du README).

## Commandes au clavier

| Touche | Action |
|---|---|
| Flèches ou Z Q S D | Déplacer Junior |
| Espace, Ctrl ou Entrée | Sauter / attraper |
| 1 / 2 | Game A / Game B |
| H | Heure |
| L | Alarme |
| R | ACL (remise à zéro) |
| V | Changer de tableau (parmi ceux débloqués) |
| O | Son : original (bip) ou symphonique |
| G | Segments LCD éteints |
| F | Plein écran (le cadre disparaît) |
| M | Couper le son |
| Échap | Menu |

## Manette (Xbox, PlayStation, Switch Pro)

| Bouton | Action |
|---|---|
| Croix ou stick gauche | Déplacer Junior |
| A / B | Sauter |
| Start / Select | Game A / Game B |
| X / Y | Heure / Alarme |
| LB | Changer de tableau |
| RB | Son original / symphonique |
| LT | Menu |
| RT | Défi final |

Le navigateur n'autorise le son qu'après un clic ou une touche du clavier : clique une fois dans la page si tu joues uniquement à la manette.

## Les boutons autour du cadre

- **Jouer** : Game A, Game B, Défi final (Monde Dark, la partie commence à 980 points).
- **Tableaux** : les 8 univers, avec les points à atteindre pour ceux qui sont encore verrouillés.
- **En ligne** : classement, trophées, revoir la fin.
- **Console** : Heure, Alarme, ACL.
- **Son**, **Affichage** (plein écran, segments LCD), **Aide**.

## Sauvegarde

Le record, les tableaux et les trophées sont enregistrés dans le navigateur. Si tu changes de navigateur ou que tu effaces ses données, ils repartent à zéro.
