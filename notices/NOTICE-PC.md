# Notice — version PC (V4.1)

## Installation

1. Télécharge [`DKJr-Panorama-Remaster-V4.1-PC.zip`](../telechargements/DKJr-Panorama-Remaster-V4.1-PC.zip) et décompresse-le.
2. Ouvre le fichier `Donkey Kong Jr. Panorama - Remaster V4.1.html` avec Chrome, Edge ou Firefox.
3. Au premier lancement, le jeu demande la **ROM d'origine** (voir le [README](../README.md#-rom-dorigine-non-fournie)) :
   clique sur **Choisir les fichiers** et sélectionne `gnw_dkjrp.zip`, ou les deux fichiers `cj-93.program` et `cj-93.melody`.
   Elle est mémorisée : c'est à faire une seule fois.

Tu peux aussi jouer directement en ligne, sans rien installer, depuis la page du projet (lien en haut du README).

## Commandes au clavier

| Touche | Action |
|---|---|
| Flèches ou Z Q S D | Déplacer Junior |
| Espace, Ctrl ou Entrée | Sauter / attraper |
| 1 / 2 | Game A / Game B |
| H | Heure |
| L | Alarme |
| R | ACL (remise à zéro) |
| V | Changer de tableau (parmi ceux débloqués) |
| O | Son : original (bip) ou symphonique |
| G | Segments LCD éteints |
| F | Plein écran (le cadre disparaît) |
| M | Couper le son |
| Échap | Menu |

## Manette branchée en USB (ou Bluetooth)

1. Branche la manette au PC **avant ou après** avoir ouvert le jeu.
2. Appuie sur **n'importe quel bouton** de la manette : le navigateur ne la montre au jeu qu'à ce moment-là.
   Le panneau de droite affiche alors « 🎮 Manette connectée ✓ ».
3. Clique une fois dans la page (ou appuie sur une touche du clavier) pour que le son démarre.

Fonctionne avec Chrome, Edge et Firefox.

### Manettes Xbox, PlayStation, Switch Pro (et la plupart des manettes récentes)

| Bouton | Action |
|---|---|
| Croix ou stick gauche | Déplacer Junior |
| A / B | Sauter |
| Start / Select | Game A / Game B |
| X / Y | Heure / Alarme |
| LB | Changer de tableau |
| RB | Son original / symphonique |
| LT | Menu |
| RT | Défi final |

### Manettes USB génériques (style Super Nintendo, manettes « no name »)

| Bouton | Action |
|---|---|
| Croix | Déplacer Junior |
| Les 4 boutons de face | Sauter |
| Start / Select | Game A / Game B |
| L / R | Changer de tableau / Son |

Si une manette ne réagit pas, ouvre le site https://hardwaretester.com/gamepad avec le même navigateur, appuie sur un bouton et vérifie qu'elle apparaît : sinon c'est un problème de pilote ou de câble.

## Les boutons autour du cadre

- **Jouer** : Game A, Game B, Défi final (Monde Dark, la partie commence à 980 points).
- **Tableaux** : les 8 univers, avec les points à atteindre pour ceux qui sont encore verrouillés.
- **En ligne** : classement, trophées, revoir la fin.
- **Console** : Heure, Alarme, ACL.
- **Son**, **Affichage** (plein écran, segments LCD), **Aide**.

## Sauvegarde

Le record, les tableaux et les trophées sont enregistrés dans le navigateur. Si tu changes de navigateur ou que tu effaces ses données, ils repartent à zéro.
